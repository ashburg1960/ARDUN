# ARDUN | Rattan E-Commerce
A modern, responsive e-commerce landing page designed to showcase handcrafted rattan furniture and sustainable home decor. This project focuses on a clean user interface and intuitive navigation to provide a seamless shopping experience.
## 🚀 Features
 * Responsive Design: Optimized for various screen sizes, from mobile to desktop.
 * Product Showcase: Clean layout for highlighting high-quality furniture imagery.
 * Modern UI: Styled with a focus on natural aesthetics and minimal design.
## 🛠️ Tech Stack
 * HTML5: Semantic structure for better SEO and accessibility.
 * CSS3: Custom styling including Flexbox and Grid for layout management.
 * JavaScript: Interactive elements to enhance user engagement.
